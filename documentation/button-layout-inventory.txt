Button / control layout inventory
=================================
Captured: 2026-07-24
Purpose: Baseline ABS positions before Seifer moves controls for default (Noto) font.
Workflow: Seifer adjusts default-mode buttons → we note which ones moved →
          those same controls get a second set of coords for retro mode.

Layout types
------------
  LAY = layout-managed (auto position; usually no per-mode move needed)
  ABS = absolute geometry in .ui (likely need default vs retro coordinates)

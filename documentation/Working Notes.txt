Working Notes
=============
Scratch file for unreleased changes. Do not create vVERSION.md here —
the version is unknown until publish (rc.N, beta.N, or full vX.Y.Z).

Write one bullet per change (bug fix, feature, or TASK). Include a
GitHub issue number when there is one.

publishRelease.py copies these bullets under ## Changes in
documentation/releases/vVERSION.md (no Working Notes heading), then
resets this file to this template.

- Options uses a left category list (General / Appearance / Oracle / Aquarius /
  USBR / USGS) with Kate-style icon+label rows
- Appearance: Retro Mode and Color Theme (System / Light / Dark)
- Oracle credentials and TNS moved off USBR; Databases Access List; Update
  Password only hits checked HDBs (Save no longer starts a password change)
- USBR Overwrite Flag; Add Data Type to Labels is per USBR / Aquarius / USGS

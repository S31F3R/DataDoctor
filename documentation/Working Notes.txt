Working Notes
=============
Scratch pad for the next packaged release. Grok adds bug fixes (with GitHub
issue # when there is one), features, and TASKS here. Seifer copies into
documentation/releases/vVERSION.md. publishRelease.py clears this file.

- Data Dictionary combobox cells no longer overlay cell text on the dropdown
- Close on Windows no longer raises RuntimeError (deleted QTableWidget) or
  opens two GitHub report tabs
- Report on GitHub uses a short crash-form URL and copies the full log to
  the clipboard (long body= URLs were GitHub "Whoops, something went wrong!")
- MCS Oracle: first connect per DSN is serialized; sessions are pooled so
  threads do not each prompt for Windows credentials
- Instant Client sqlnet.log Fatal entries are copied into app.log as ERROR
- Windows/mac packages include an empty Project Files/certs/; applyUpdate
  never replaces user Aquarius certs
- Linux/mac .venv is not packaged for Windows (OS-specific). First-run
  applyUpdate.cmd creates Project Files\.venv from the Python zip in Update\
- bunker.db merge fills blanks only for valuePrecision, precisionOverride,
  expectedMin, expectedMax, cuttoffMin, cutoffMax, rateOfChange
- scripts/updateBunkerFromCsv.py updates bunker.db from USBR CSV exports
- Options → Beta updates: checking Save runs a GitHub check; unchecking
  offers the last published (non-RC/beta) release
- Working Notes + publishRelease seed/clear on packaged release

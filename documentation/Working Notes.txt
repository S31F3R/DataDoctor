Working Notes
=============
Scratch file for unreleased changes. Do not create vVERSION.md here —
the version is unknown until publish (rc.N, beta.N, or full vX.Y.Z).

Write one bullet per change (bug fix, feature, or TASK). Include a
GitHub issue number when there is one.

publishRelease.py copies these bullets under ## Changes in
documentation/releases/vVERSION.md (no Working Notes heading), then
resets this file to this template.

- Log Viewer tab uses the Notebook icon
- An applied Windows zip moves under updates/held so the launcher opens the app
- Refresh puts a moved equation column back at the column it was moved to
- Aligned regression uses a lag slider per series and refits the equation when a slider moves
- Fill handle stays on the cell corner when a column is resized
- A formula with a space after = still graphs
- Regression tab icon returns after the tab is detached and attached

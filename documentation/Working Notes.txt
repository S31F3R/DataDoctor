Working Notes
=============
Scratch file for unreleased changes. Do not create vVERSION.md here —
the version is unknown until publish (rc.N, beta.N, or full vX.Y.Z).

Write one bullet per change (bug fix, feature, or TASK). Include a
GitHub issue number when there is one.

publishRelease.py copies these bullets under ## Changes in
documentation/releases/vVERSION.md (no Working Notes heading), then
resets this file to this template.

- 3.0.x → 3.1 applyUpdate.cmd starts Data Doctor.exe when the Windows zip hop finishes (app was closed)
- Windows launcher is generic: pythonFiles\app.pyw (DataDoctor.py renamed) + pythonFiles\python-embed; DataDoctor.ico is the exe icon
- Launcher starts applyUpdate.cmd and exits if Update\ has a zip; applyUpdate always starts Data Doctor.exe when done (so the .exe can be replaced)
- macOS packages use pythonFiles/ (same as Windows), not Project Files/

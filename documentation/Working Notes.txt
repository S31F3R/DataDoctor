Working Notes
=============
Scratch file for unreleased changes. Do not create vVERSION.md here —
the version is unknown until publish (rc.N, beta.N, or full vX.Y.Z).

Write one bullet per change (bug fix, feature, or TASK). Include a
GitHub issue number when there is one.

publishRelease.py copies these bullets under ## Changes in
documentation/releases/vVERSION.md (no Working Notes heading), then
resets this file to this template.

- GitHub reporting uses the OAuth App (device flow, public client id). About → Report issue and crash Report on GitHub file the issue as the signed-in user; token is stored in the OS keyring (`githubToken`), not user.config
- First-install UTC offset defaults to the computer’s current timezone (Windows / Linux / macOS, including DST)
- Utils.py: QUERY_* constants and private helpers renamed to camelCase

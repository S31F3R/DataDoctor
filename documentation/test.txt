[x] New app icon is easier to see
   Steps:
     a. Start Data Doctor. The window icon is the wizard with a black outline
        and a yellow glow, so it reads on a light bar and a dark bar.
     b. That icon is ui/icons/DataDoctor.png and ui/icons/Data Doctor.ico.
        The same ico is in launcher/ and launcher/src/.
     c. Rebuild Data Doctor.exe on Windows for the Explorer icon.
        The About window still uses the starfield title.

[ ] Plotter legend uses the dictionary name
   Steps:
     a. Data Dictionary has a common name for a Data ID you will plot.
        Options: Add Data Type to Labels is on for that source
        (USBR, USGS, or Aquarius — each source has its own checkbox).
     b. Plot Line, Scatter, or Time Lag that includes that Data ID.
     c. The legend is commonName-datatype. Turn that source's checkbox off,
        plot again, and the legend is the common name only.
     d. A Data ID that is not in the dictionary still uses the site name
        or the Data ID.

[ ] Plotter HDB uses SQL when the API misses
   Steps:
     a. Oracle credentials are saved. Plot a USBR Oracle series (LCHDB,
        UCHDB2, YAOHDB, or another HDB) whose public API call fails or
        does not include that SDID.
     b. The series still plots. The log says it is trying the Oracle connection.
     c. USBR-PNHYD, USBR-GPHYD, USGS, and Aquarius stay on the API.
        A series the public API returns with no points is not read from SQL.

[ ] Passive update check notices a new beta
   Steps:
     a. Options: Beta updates is on. Leave Data Doctor open.
     b. Publish a newer rc or beta.
     c. Within about 15 minutes the update window appears. It does not wait
        hours. If you already clicked Later on an older build, the newer one
        still appears.

[ ] Linux bunker merge answers
   Steps:
     a. AppImage: when the packaged dictionary differs, two questions appear
        after the window opens (Common Names, then Data Types). No defaults
        to Yes.
     b. Linux update apply (no console): the log says it is answering N to
        both. Existing common names and data types stay. New rows still
        get the packaged names and types.

[ ] Mac package script
   Steps:
     a. From project root: python scripts/packageMac.py --skip-venv
     b. Zip contains Data Doctor.app, Data Doctor.command, Clear Quarantine.command,
        pythonFiles/python-embed-arm64 and python-embed-x86_64 (bundled CPython).
     c. On a Mac: unzip, Right-click Data Doctor.app → Open (Gatekeeper). No system Python.
     d. If blocked: Clear Quarantine.command (Right-click → Open), then the app.
     e. Optional on Mac only: python scripts/packageMac.py --app → frozen PyInstaller .app.

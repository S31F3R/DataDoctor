Current Tests
--------------------------------------------------------------------------------
[ ] 3.0.0 reaches the current launcher command
   Steps:
     a. From a 3.0.0 install, take the in-app update. The first zip is
        the Python zip. That updater does not download the Windows zip.
     b. Restart. The app says this install still uses system Python and
        will restart to finish the install. The only button is OK.
        Download and Later are not on that box.
     c. Click OK. A DataDoctor-Windows zip already in updates\ is used
        and is not downloaded again. Otherwise it downloads. There is
        no second Restart / Later box. Data Doctor closes and
        applyUpdate runs.
     d. Data Doctor.exe is replaced and pythonFiles\python-embed is
        installed. A second restart appears only if the command or that
        Python could not be replaced while they were in use.
     e. After the app opens and that install is finished, the zip is
        removed on its own. app.log says it removed the applied update.
        The zip is still in updates\ if the install is not finished.

[ ] Query list names row and column equations
   Steps:
     a. Append an equation row and rename it Total. The query list shows
        ROW EQUATION|Total at the bottom.
     b. Type a formula in a custom column named Stage. The query list
        shows COLUMN EQUATION|Stage.
     c. Save the Quick Look, clear the list, and load it. Both lines
        come back with those names.
     d. An older Quick Look that still says ROW|Total or EQUATION|Stage
        still loads. Saving it writes the new names.

[ ] Plotter HDB uses SQL when the API misses
   Steps:
     a. Oracle credentials are saved. Plot a USBR Oracle series (LCHDB,
        UCHDB2, YAOHDB, or another HDB) whose public API call fails or
        does not include that SDID.
     b. The series still plots. The log says it is trying the Oracle connection.
     c. USBR-PNHYD, USBR-GPHYD, USGS, and Aquarius stay on the API.
        A series the public API returns with no points is not read from SQL.

[ ] Mac package script
   Steps:
     a. From project root: python scripts/packageMac.py --skip-venv
     b. Zip contains Data Doctor.app, Data Doctor.command, Clear Quarantine.command,
        pythonFiles/python-embed-arm64 and python-embed-x86_64 (bundled CPython).
     c. On a Mac: unzip, Right-click Data Doctor.app → Open (Gatekeeper). No system Python.
     d. If blocked: Clear Quarantine.command (Right-click → Open), then the app.
     e. Optional on Mac only: python scripts/packageMac.py --app → frozen PyInstaller .app.

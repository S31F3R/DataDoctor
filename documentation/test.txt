Current Tests
--------------------------------------------------------------------------------
[ ] Aligned lag sliders refit the equation
   Steps:
     a. Run Regression on two or more series. Open the Regression tab and
        choose Aligned.
     b. Each series except the one you predicted has a slider in that line's
        color. r², NSE, ME, RMSE, and N sit above the slider. The readout
        shows the lag in steps and clock time. Warnings sit under the sliders.
     c. Aligned does not repeat the Y line or the lag summary. Relationship
        still shows them.
     d. Move a slider. That line shifts, its stats change, and Relationship's
        Y equation uses the new lag.
     e. Zoom the time axis. The stats above the sliders follow the visible window.

[ ] Fill handle follows a column resize
   Steps:
     a. Select a cell that shows the green fill square.
     b. Drag that column's right edge. The square stays on the bottom-right
        corner of the cell. It does not wait until you click another cell.

[ ] A formula with a space after = still graphs
   Steps:
     a. Insert a custom column. Enter = 0.0613*A1 + 41.116 with a space after =.
        The cell shows a number, not the formula text.
     b. Graph that column together with the series it uses. The equation
        column is on the graph.
     c. Graph only that column. It plots. It does not say
        "No numeric series found to graph."

[ ] Regression tab icon comes back after detach
   Steps:
     a. Open Regression. The tab shows the regression icon.
     b. Right-click the tab, choose Detach, then right-click the floating tab
        and choose Attach.
     c. The regression icon is on the tab again.

[ ] Plotter HDB uses SQL when the API misses
   Steps:
     a. Oracle credentials are saved. Plot a USBR Oracle series (LCHDB,
        UCHDB2, YAOHDB, or another HDB) whose public API call fails or
        does not include that SDID.
     b. The series still plots. The log says it is trying the Oracle connection.
     c. USBR-PNHYD, USBR-GPHYD, USGS, and Aquarius stay on the API.
        A series the public API returns with no points is not read from SQL.

[ ] Mac package script
   Steps:
     a. From project root: python scripts/packageMac.py --skip-venv
     b. Zip contains Data Doctor.app, Data Doctor.command, Clear Quarantine.command,
        pythonFiles/python-embed-arm64 and python-embed-x86_64 (bundled CPython).
     c. On a Mac: unzip, Right-click Data Doctor.app → Open (Gatekeeper). No system Python.
     d. If blocked: Clear Quarantine.command (Right-click → Open), then the app.
     e. Optional on Mac only: python scripts/packageMac.py --app → frozen PyInstaller .app.

[ ] Windows update opens the app after apply
   Steps:
     a. From a machine that has just applied a zip, applyUpdate.cmd runs
        to the end, says it is keeping the zip, and starts Data Doctor.exe.
        The app stays open.
     b. updates\ has no *.zip sitting directly in that folder. The zip is
        under updates\held\ until the app opens and the install is finished.
        app.log then says it removed the applied update.
     c. A second applyUpdate.cmd does not start by itself.
     d. A machine already looping: close the repeating cmd, and move or
        delete the zip sitting directly in updates\. Update again with a
        build that parks the zip.

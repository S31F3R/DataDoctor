     d. No GitHub token / password fields in Options.

[ ] HDB database-link failure → direct connect fallback
   Steps:
     a. Internal query mixing UCHDB2 / LCHDB / YAOHDB (they share links).
     b. If @link fails, retry connects directly to the target DSN.
        Any worker error on a linked query now triggers that retry
        (not only ORA-02019).
     c. Query still returns data when the direct path works.
     d. KBOHDB / CUHDB / LBOHDB / ECOHDB never use @link; each is its own
        worker with a direct connection (same idea as USGS vs Aquarius).
   Notes: RESPONSE said fallback was not working. sqlRead now retries
     direct on any linked-query failure, resets primaryDsn each executeQuery,
     and never sets primary from an isolated HDB.

        should reuse pooled sessions (no new prompt until OS cache expires).
     c. FILE wallet / non-MCS path unchanged.

        Same timestamp window as the failure.

[ ] Plotter HDB uses SQL when the API misses
   Steps:
     a. Oracle credentials are saved. Plot a USBR Oracle series (LCHDB,
        UCHDB2, YAOHDB, or another HDB) whose public API call fails or
        does not include that SDID.
     b. The series still plots. The log says it is trying the Oracle connection.
     c. USBR-PNHYD, USBR-GPHYD, USGS, and Aquarius stay on the API.
        A series the public API returns with no points is not read from SQL.

[ ] Mac package script
   Steps:
     a. From project root: python scripts/packageMac.py --skip-venv
     b. Zip contains Data Doctor.app, Data Doctor.command, Clear Quarantine.command,
        pythonFiles/python-embed-arm64 and python-embed-x86_64 (bundled CPython).
     c. On a Mac: unzip, Right-click Data Doctor.app → Open (Gatekeeper). No system Python.
     d. If blocked: Clear Quarantine.command (Right-click → Open), then the app.
     e. Optional on Mac only: python scripts/packageMac.py --app → frozen PyInstaller .app.

[ ] Windows update opens the app after apply
   Steps:
     a. From a machine that has just applied a zip, applyUpdate.cmd runs
        to the end, says it is keeping the zip, and starts Data Doctor.exe.
        The app stays open.
     b. updates\ has no *.zip sitting directly in that folder. The zip is
        under updates\held\ until the app opens and the install is finished.
        app.log then says it removed the applied update.
     c. A second applyUpdate.cmd does not start by itself.
     d. A machine already looping: close the repeating cmd, and move or
        delete the zip sitting directly in updates\. Update again with a
        build that parks the zip.

[x] Refresh keeps moved equation columns
   Steps:
     a. Query 3 series. Insert a custom column on the far right and enter
        an equation. Move it to column B. Refresh. The formula fills the
        new date range.
     b. Insert a 5th column at the end with another equation. Move it to
        column C. Refresh.
     c. Both stay equations. Neither column shows #CYCLE!. The letters
        still refer to the same series they did before the refresh.
     d. With debug on, the log shows the column move (old formula to new)
        and the refresh restore index for each equation column.

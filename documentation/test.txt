[ ] Plotter toolbar opens a plot query
   Steps:
     a. The toolbar button tooltip is Plotter. It opens the Plotter window.
        It does not graph the Data Query table.
     b. Right-click a table header or cells → Graph still graphs the table.
     c. Plot Types are radios: Line (default), Scatter, Time Lag.
     d. The database list includes Aquarius and the HDB names. There is no
        Overlay, Display Deltas, Raw, or QAQC. List right-click is Insert Above,
        Insert Below, and Delete.

[ ] Plotter Line, Scatter, and Time Lag
   Steps:
     a. Line: one or more Data IDs, then Plot. A tab titled Plotter-Line opens
        to the right of Regression (or Graph, if Regression is closed). Each
        series is its own line. The Data Query table does not change.
     b. Run Scatter from that same window. The same tab retitles to
        Plotter-Scatter. It does not open a second Plotter tab.
        Scatter with one Data ID warns and does not run. With two, the first
        list row is X and the second is Y.
     c. Time Lag needs at least two Data IDs, upstream first and downstream
        last. The tab retitles to Plotter-Time Lag. The slider runs from 0 up
        to a max taken from the data. The readout shows steps and clock time,
        like 12 steps (3:00), and a correlation.
     d. Drag the slider. The last line and the correlation update live.
        Zoom or pan the time axis. The lines refit, and the correlation is for
        the time window on screen.
     e. Save a Plot Quick Look, load it, and Plot again. The plot type comes
        back, and Time Lag restores the slider lag you saved.
     f. Options → Export / Import includes Plot Quick Looks.
     g. Detach the Plotter tab. It minimizes to the Data Doctor taskbar button.
        Attach puts it back.

[ ] Equation formula stays A1 on a new date range
   Steps:
     a. On a custom column, enter a formula that uses A1 (or D1). Save it in a Quick Look.
     b. Load that Quick Look and Query a different month.
     c. The equation still calculates. It is not #REF!.
     d. Insert a column to the left of a referenced column (Insert column right
        on the column before D). D becomes E in the formula, and in the Quick Look.
     e. Remove a column to the left of that ref. The letter moves back.
     f. Drag a referenced column to a new spot. The formula letter follows it.
     g. Dual-input Quick Look: the formula column is C, written on row 4 as
        =0.5412*A1 + 0.4521*D10 + 32.291 (A1 is 3 hours back, D10 is 6 ahead).
        Load it and Query. The formula still starts on C4 with A1 and D10.
        It does not move to C1. Rows 1–3 stay blank. Rows where D runs off
        the sheet stay blank. No #REF! for those.

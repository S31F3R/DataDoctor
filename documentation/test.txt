Current Tests
--------------------------------------------------------------------------------
[ ] Update available does not stack
   Steps:
     a. Leave Data Doctor open until Update available appears. Do not click
        Download or Later.
     b. Leave that window up through another background check (about 15 minutes).
        Saving Options so it checks again, while the window is still open,
        counts too.
     c. A second Update available window does not appear. Download and the
        Restart window that follows also stay one window.
     d. Click Later, or close the window. A newer release can still prompt.

[ ] Plotter HDB uses SQL when the API misses
   Steps:
     a. Oracle credentials are saved. Plot a USBR Oracle series (LCHDB,
        UCHDB2, YAOHDB, or another HDB) whose public API call fails or
        does not include that SDID.
     b. The series still plots. The log says it is trying the Oracle connection.
     c. USBR-PNHYD, USBR-GPHYD, USGS, and Aquarius stay on the API.
        A series the public API returns with no points is not read from SQL.

[ ] Linked HDB queries run together
   Steps:
     a. Internal query with series from at least two of LCHDB, UCHDB2, and
        YAOHDB in the same run.
     b. The log says each of those databases is on its own thread and opens
        its own session. Values come back for each series.
     c. A query with only one of those databases still returns values.
     d. KBO, CU, LBO, and ECO still connect directly.

[ ] About stars drift behind the title
   Steps:
     a. Open About. The stars drift. The green DATA DOCTOR title stays put.
     b. Resize the window. The stars keep moving and the title stays readable.
     c. Close About and open it again. The stars move again.

[ ] Windows update uses the Windows package
   Steps:
     a. On a Windows install that already has python-embed, check for updates.
     b. The downloaded file name contains Windows (DataDoctor-Windows-*.zip).
     c. After Restart, Data Doctor.exe and Data Doctor.ico match that package.

[ ] Windows apply does not replace the running Python
   Steps:
     a. Close Data Doctor. Put a DataDoctor-Windows zip in updates and run
        applyUpdate.cmd.
     b. It finishes without "Access is denied" on python.exe, and without
        the '" (' is not recognized message.
     c. Data Doctor starts when the updater exits. The exe and icon are new.
     d. pythonFiles\scripts\applyUpdate.py is the script. There is no
        applyUpdate.py in the install root, and no python-standalone folder.

[ ] Query and plotter tabs show icons
   Steps:
     a. A public Data Query tab shows the public icon. An internal query
        switches that tab to the internal icon.
     b. SQL Query Builder shows the SQL icon.
     c. Plotter Line shows the plotter icon. Scatter shows the scatter icon.
        Time Lag shows the time lag icon. Changing the plot type changes
        the icon. Graph shows the plotter icon.
     d. Detach a plotter. The floating window keeps the normal Data Doctor
        icon and its Data Doctor title. The special icon is only on the tab.

[ ] Dictionary merge keeps QAQC values you set
   Steps:
     a. Set precisionOverride, expectedMin, and expectedMax on a dictionary
        row. Leave those fields blank on a different row.
     b. Apply an update so the packaged bunker.db merges.
     c. The values you set are unchanged, including a value of 0.
        The blank fields fill from the packaged dictionary.

[ ] CSV bunker update accepts a folder or *.csv
   Steps:
     a. From the project root, run updateBunkerFromCsv.py with a folder of
        CSV files, or with a quoted pattern such as "C:\Temp\Exports\*.csv".
     b. It reads every csv. It does not stop with "CSV not found" for the
        pattern itself.
     c. It asks about common names and data types before the merge starts.

[ ] Mac package script
   Steps:
     a. From project root: python scripts/packageMac.py --skip-venv
     b. Zip contains Data Doctor.app, Data Doctor.command, Clear Quarantine.command,
        pythonFiles/python-embed-arm64 and python-embed-x86_64 (bundled CPython).
     c. On a Mac: unzip, Right-click Data Doctor.app → Open (Gatekeeper). No system Python.
     d. If blocked: Clear Quarantine.command (Right-click → Open), then the app.
     e. Optional on Mac only: python scripts/packageMac.py --app → frozen PyInstaller .app.

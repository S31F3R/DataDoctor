Current Tests

[ ] Plotter HDB uses SQL when the API misses
   Steps:
     a. Oracle credentials are saved. Plot a USBR Oracle series (LCHDB,
        UCHDB2, YAOHDB, or another HDB) whose public API call fails or
        does not include that SDID.
     b. The series still plots. The log says it is trying the Oracle connection.
     c. USBR-PNHYD, USBR-GPHYD, USGS, and Aquarius stay on the API.
        A series the public API returns with no points is not read from SQL.

[ ] Windows update keeps Python and finishes the launcher
   Steps:
     a. If a command window from the last try is still open, press Ctrl+C
        and close it before starting another update.
     b. From the new DataDoctor-Windows zip, copy
        pythonFiles\scripts\applyUpdate.py over the installed
        pythonFiles\scripts\applyUpdate.py. Put that zip in updates and
        run applyUpdate.cmd.
     c. No command window stays open on find. python-embed is not copied
        again when that Python is already installed. Data Doctor.exe and
        Data Doctor.ico still update.
     d. Data Doctor opens. If applyUpdate.cmd.new is present, the window
        lists what is left and offers Restart and Later.
     e. Later leaves those files and does not ask again until the next
        launch. Restart closes Data Doctor, replaces applyUpdate.cmd with
        the new command, finishes whatever is still staged, and opens
        Data Doctor again.

[ ] CSV bunker update accepts a folder or *.csv
   Steps:
     a. From the project root, run updateBunkerFromCsv.py with a folder of
        CSV files, or with a quoted pattern such as "C:\Temp\Exports\*.csv".
     b. It reads every csv. It does not stop with "CSV not found" for the
        pattern itself.
     c. It asks about common names and data types before the merge starts.
     d. The merge finishes in seconds, like the bunker merge, including a
        folder of exports.

[ ] Mac package script
   Steps:
     a. From project root: python scripts/packageMac.py --skip-venv
     b. Zip contains Data Doctor.app, Data Doctor.command, Clear Quarantine.command,
        pythonFiles/python-embed-arm64 and python-embed-x86_64 (bundled CPython).
     c. On a Mac: unzip, Right-click Data Doctor.app → Open (Gatekeeper). No system Python.
     d. If blocked: Clear Quarantine.command (Right-click → Open), then the app.
     e. Optional on Mac only: python scripts/packageMac.py --app → frozen PyInstaller .app.

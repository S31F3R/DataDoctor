# Data Doctor 3.0.1

Channel: published

## Changes

- Options Save keeps the window open; Cancel reads Close when nothing changed
- Options General: Profile: label next to Import/Export; Raw Data / QAQC moved to Query
- Query Options: Raw Data and QAQC checkboxes (default off; stored on Quick Looks)
- Quick Looks remember Custom vs Prev Day / Prev Week (rolling modes refresh from now)
- Query list: multi-select delete and move; insert disabled on multi-select; edge-safe reorder
- Data ID Search includes siteID; dataID/siteID sort numbers first then text
- Wiki: dataID / siteID per source; Oracle TNS_ADMIN vs packaged network/admin
- Packaged Instant Client always; TNS_ADMIN set before init (not client/network/admin)
- QSplitter setCollapsible after widgets are added (no index-out-of-range warnings)
- Icon buttons restore normal image after a modal (same hover fix as History)
- Windows System/Light: Fusion so checkbox/radio indicators are not dark-on-light
- Query: Select Quick Look no longer overlaps Raw Data
- Query list multi-select move no longer crashes (QListWidgetItem is unhashable)
- Icon hover: re-sync from real cursor after dialogs, errors, and mouse moves
- Re-apply bundled Noto/Press Start after theme style changes (Windows was dropping to Segoe UI)

## Notes

Windows launcher updates use the `DataDoctor-Python-*.zip` asset (`Update\` + `applyUpdate.cmd`).

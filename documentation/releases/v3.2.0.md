# Data Doctor 3.2.0

Channel: published

## Changes

- Custom Quick Look dates: Save asks how to interpret the range (current time, today at clock, last N days, weekly weekday, omit, exact). Load/Query apply the chosen rule (#3)
- Quick Look Date Range dialog: title case; list tall enough for 5 options
- Quick Look Date Range: end at 00:00 offers current time through midnight N days from today, not a raw minute count
- Default (non-retro) Data Query toolbar button positions adjusted
- publishRelease.py reads collapsed Confirmed titles (plain lines, not only `[x] Title`) so a published 3.2.0 can fold/clear the test log
- Windows update dialog: short “Hit Restart to update…” with a Restart button that runs applyUpdate.cmd; Python-zip hops can chain-download the Windows package when python-embed is still missing
- First-run launcher: refuse zip-preview / exe-only extracts with a clear message; log format matches Python `YYYY-MM-DD HH:MM:SS,mmm [LEVEL]`; applyUpdate.py also shipped at zip root
- Graph, Options, and About first-open: matplotlib/pygame import and Graph panel warm up after the main window shows (About UI still lazy — constructing it at startup killed some VMs)
- Retro UI font is Silkscreen (same 8-bit arcade look as Press Start 2P, different maker; Press Start stays for About arcade games)
- SQL editor Ctrl+Y redo (Linux default was Ctrl+Shift+Z only)
- Drag column headers to reorder (header click filter no longer eats the press)
- Single-click header highlights the column; double-click sorts (Qt built-in sort stays off)
- Retro-mode restart: do not crash on deleted QTableWidget / LogNotifier; hide pygame support prompt
- Data Query Ctrl+Z / Ctrl+Y undo and redo (SQL keeps the editor’s built-in undo)
- Header Insert column left/right (blank custom columns survive Refresh, graph, CSV, formulas, details)
- Drag headers to reorder columns; query list follows; overlay+delta stay locked; custom columns move independently
- Overlay header Swap Primary/Secondary; cell Update from secondary (HDB only, differing cells)
- Rename any header’s common name; next new query can save/update the Data Dictionary
- Overlay display uses the primary rounding spec when Raw Data is off
- Graph legend no longer has a “Click to show/hide” title; missing data leaves a gap instead of a straight line
- Query list up/down arrows keep scroll position unless the moved row leaves the view
- Double-clicking a cell without changing it no longer paints a black background
- Light/Dark theme switch restyles SQL editors, snippet pane, and scrollbars (no more stale light-grey SQL text)
- Query Data closes the query window before the progress dialog so a second query cannot hide behind it
- Retro spacing matches non-retro for now (`Utils.retroUseDefaultSpacing`); font + neon chrome stay. Inventory is in `core/Utils.py` (search RETRO MODE INVENTORY)
- Column drag: insert line while dragging; non-overlay delta trios (primary+secondary+delta) stay locked; intra-trio data swap recalculates delta; drop into another pair lands after that pair
- Utils.py font knobs: `defaultFontSizeAdjust` / `retroFontSizeAdjust` (retro starts at +2 so Silkscreen is not tiny; 0 = previous sizes)
- Overlay swap uses full headers (dataID line), recalculates delta from the new primary rounding, and resizes the column; Update from secondary is undoable
- Overlay compare/format both values with the primary spec so 642.272 vs 642.2724 is not red; Overlay Details match that precision
- Public custom columns are editable (formulas + fill are not database edits); header Show details is populated
- Formula Tab completes functions with a tooltip; Esc cancels; pointed cells get a colored ring matching the A1 token; formula-on-data strips paint and Ctrl+Z restores it (undo includes colors)
- Rename header prompts to save the Data Dictionary name before Query/Refresh; unsaved names are not kept on Refresh; rename/swap resize the column
- Retro applies live like Light/Dark; query window ~4 characters wider; info buttons (except Data ID) and Refresh/Undo/Upload use retro positions; tab text #323232; light+retro scrollbar track is not black
- Graph restyles on Light/Dark/Retro; retro toolbar is green
- SQL query/result splitter uses the same dotted grabber as snippets (green in retro)
- About retro line-height tightened; applyUpdate no longer prints Updates/ rename; QFFmpeg disconnect warnings on About close are filtered
- Formula `=` shows a function list (arrows + Tab/Enter insert); Enter commits the cell instead of a newline
- Live retro applies Silkscreen to tabs, labels, combos, and Options sidebar items; Options Save no longer shrinks UTC Offset / radios
- Retro query width is Windows-only (~2 characters); Linux stays original. Load/Save/Clear/Delete Quick Look are 1pt smaller
- Retro timestamp row pad reduced; live retro resizes Data Query columns; SQL pin moves 14px left; graph legend/ticks use Silkscreen
- Overlay details no longer crash on a string UserRole / wrong-DB fallback; overlay cells stay editable after swap
- Overlay swap clears red when the pair matches at the new primary rounding (no Refresh needed)
- USBR Show details keeps list responses (was wrapping them and showing blank)
- Live retro no longer inflates the timestamp rail; Query radios/checkboxes are small again; Windows query width ~56px extra; SQL pin 10px
- Graph legend/ticks +1pt, axis labels +2pt in retro
- Dragged columns keep their widths; renaming a header back to the dictionary name is not a pending save
- `updateBunkerFromCsv.py` asks y/n to update Common Names and Data Types (#5)
- Data Dictionary and Data ID Search: Filter/Filtered icons on siteID and database headers (combobox, right-click clear); type-search no longer uses siteID (#4)
- Live retro resizes data columns again; timestamp rail uses Qt sizeHint (drag still works); Windows query extra width ~96px
- siteID header filter is a typed box (substring); database list opens on the first click
- Retro timestamp rail width uses tightBoundingRect (no left/right gap around the date/time)
- Timestamp rail is fixed to ink width (sizeHint was still widening it; center-align made the gap)
- Timestamp rail uses the same horizontalAdvance+22 sizing as data columns (tightBoundingRect clipped the trailing 00)
- Query search icon tooltip: “Data ID Search”
- Retro graph toolbar: icons tinted neon green; button borders stay normal chrome (no green box)
- Retro + Light keeps a light graph (black text/icons, Silkscreen); neon green plot is Dark + retro only
- Dropped `Utils.retroUseDefaultSpacing` and the old Press Start extra-spacing
  branch; retro keeps Noto padding plus `retroAlwaysLayouts` (Refresh/Undo/Upload
  at 54/90/126)
- Unchecking Beta updates is silent when already on a published build; revert
  dialog only if the install is currently an rc/beta
- Apply-update dictionary merge asks y/n for Common Names and Data Types (#5);
  Python zip now ships `updateBunker.py`; Restart shows the applyUpdate console
  so those prompts are visible
- GitHub reporting uses the OAuth App (device flow, public client id). About → Report issue and crash Report on GitHub file the issue as the signed-in user; token is stored in the OS keyring (`githubToken`), not user.config
- First-install UTC offset defaults to the computer’s current timezone (Windows / Linux / macOS, including DST)
- Utils.py: QUERY_* constants and private helpers renamed to camelCase

- Fixes [#5](https://github.com/S31F3R/DataDoctor/issues/5): Davis units are not identified correctly
- GitHub report: first time auto-opens the browser to Authorize (one-time). Later reports skip login. Code is backup only; VS Code/git credentials are not reused.
- scripts/aquariusDictionary.py: location Identifier (or location UniqueId) → published time-series as Data Dictionary CSV (dataID=series UID, siteID=location Identifier, database=AQUARIUS); optional --apply into bunker.db
- aquariusDictionary: commonName is the time-series Label; ALL / --all exports every published series
- aquariusDictionary: USGS-######## location identifiers use the site number as siteID and the USGS monitoring-location name as siteName
- aquariusDictionary: if the time-series Label’s first '-' token is an Aquarius location Identifier, siteID/siteName come from that location

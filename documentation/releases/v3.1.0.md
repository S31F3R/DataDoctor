Channel: published

## Changes

- Aquarius TLS: verify with the OS certificate store (not certifi) plus optional certs/ CA; if both fail, HTTPS without checking the cert and a WARN (internal/VPN only). USGS still always verifies.
- Internal Data Query: Excel-style formulas (=A1+B1, SUM/IF/…, click-to-ref,
  fill handle with $ locks); overlay writes primary; errors are not uploaded
- Published releases with empty Working Notes compile ## Changes from that
  version's rc/beta notes (avoids a blank 3.0.0-style change list)
- To Do: CURRENT TASKS/BUGS are the work queue; FEATURES stay backlog until
  promoted
- Formula editor: click another cell inserts A1 (does not leave the formula)
- Windows launcher ships embeddable Python 3.14 (no system Python / .venv)
- 3.0.x Windows hop: in-app update downloads DataDoctor-Windows-*.zip; close and run applyUpdate.cmd to replace the launcher
- Requirements: Python 3.14, pygame-ce (pygame has no 3.14 wheel)
- Hardening: no unverified TLS (Aquarius/USGS); zip path checks; GitHub download host/digest/cancel; pip requirements flags ignored
- Hardening: do not log Oracle SQL text; HDB identifiers and SQL snippet names cannot traverse paths
- 3.0.x → 3.1 applyUpdate.cmd starts Data Doctor.exe when the Windows zip hop finishes (app was closed)
- Windows launcher is generic: pythonFiles\app.pyw (DataDoctor.py renamed) + pythonFiles\python-embed; DataDoctor.ico is the exe icon
- Launcher starts applyUpdate.cmd and exits if updates\ has a zip; applyUpdate always starts Data Doctor.exe when done (so the .exe can be replaced)
- Update drop folder is updates/ (3.0.x leftover Update/ still scanned)- macOS packages use pythonFiles/ (same as Windows), not Project Files/
- Options → Appearance table-color legend (double-click to change, Restore Defaults); wiki Table colors page uses the same swatches
- Options Appearance: table-color list fits without a scrollbar; Restore Defaults is a real button
- Icon file is Data Doctor.ico (space in the name)
- applyUpdate removes leftover Project Files/ after migrating to pythonFiles; renames Update/Updates to updates/
- published channel: ## Changes also picks up Confirmed tests missed in notes, then clears Confirmed
- Windows python-embed: put pythonFiles on sys.path (._pth `..` + sitecustomize + app.pyw) so Data Doctor.exe can start; import failures write startup-error.log and show a MessageBox
- applyUpdate / packager remove leftover DataDoctor.ico (icon is Data Doctor.ico)
- Windows: do not `from DataDoctor import uiMain` (app.pyw is the entry; that import was No module named DataDoctor)

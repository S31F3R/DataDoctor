# Data Doctor 3.0.0

Channel: published

## Changes

- Fixed bug with winAbout not keeping scale when resizing
- Windows build now auto installs update after close then re-open
- Fixed bug with columns not selecting in sequence when holding ctrl
- Data Dictionary combobox cells no longer overlay cell text on the dropdown
- Close on Windows no longer raises RuntimeError (deleted QTableWidget) or
  opens two GitHub report tabs
- Report on GitHub uses a short crash-form URL and copies the full log to
  the clipboard (long body= URLs were GitHub "Whoops, something went wrong!")
- MCS Oracle: first connect per DSN is serialized; sessions are pooled so
  threads do not each prompt for Windows credentials
- Instant Client sqlnet.log Fatal entries are copied into app.log as ERROR
- Windows/mac packages include an empty Project Files/certs/; applyUpdate
  never replaces user Aquarius certs
- Linux/mac .venv is not packaged for Windows (OS-specific). First-run
  applyUpdate.cmd creates Project Files\.venv from the Python zip in Update\
- bunker.db merge fills blanks only for valuePrecision, precisionOverride,
  expectedMin, expectedMax, cuttoffMin, cutoffMax, rateOfChange
- scripts/updateBunkerFromCsv.py updates bunker.db from USBR CSV exports
- Options → Beta updates: checking Save runs a GitHub check; unchecking
  offers the last published (non-RC/beta) release
- Query list right-click Delete (clicked row, or all selected)
- Internal HDB: KBOHDB / CUHDB / LBOHDB / ECOHDB use their own worker and a
  direct connection (no @link). UCHDB2 / LCHDB / YAOHDB still share links.
- Linked HDB @link failures retry a direct connect on any worker error
- Save Quick Look prefills the combo name and asks before overwrite
- Internal direct HDB SQL uses unqualified r_base / r_hour (not SCHEMA.r_base@dsn)
- Isolated HDB workers are internal-only; public USBR API stays one group
- MCS pool no longer pings idle sessions (Windows 0x80100070 cert-cache fatal)
- app.log rotation: faulthandler no longer locks the file; Windows copy+truncate
  fallback; Log Viewer reloads app.log + app.log.1…5
- sqlnet.log: ingest only bytes appended this process (no old Fatal dump);
  ERROR lines sit in the live app.log timeline
- SQL Query Builder: detachable tab, worksheets + pinned results, Stop/History,
  snippet categories, hide snippet pane (session worksheets, persisted history)
- SQL pin uses Pin vs Pinned hover/press sets; snippet splitter is a thin dotted
  grip; Categories dialog lists snippets and drag-moves them between groups
- Result-tab Pin/Pinned is painted on the tab bar (hover, press, Pin↔Pinned);
  setTabButton widgets never received those events. Pin tooltip uses Qt's
  delayed ToolTip event (no grabMouse)
- Options uses a left category list (General / Appearance / Oracle / Aquarius /
  USBR / USGS) with Kate-style icon+label rows
- Appearance: Retro Mode and Color Theme (System / Light / Dark)
- Oracle credentials and TNS moved off USBR; Databases Access List; Update
  Password only hits checked HDBs (Save no longer starts a password change)
- USBR Overwrite Flag; Add Data Type to Labels is per USBR / Aquarius / USGS
- Options Color Theme Light/Dark installs that scheme's palette (Fusion fallback)
  so tables and labels match a real system light/dark session
- Options UI lives in winOptions.ui again (Designer can edit it)
- Options General Export/Import profile zip (query Quick Looks, SQL snippets,
  user.config; no keyring)
- Options → USBR Overwrite Flag is passed as MODIFY_R_BASE OVERWRITE_FLAG ('O' or NULL)
- Graph Ctrl + mouse wheel zooms the time axis toward the pointer
- AppImage tab close icons resolve from the bundle (not CWD)
- Windows System appearance follows OS dark/light (AppsUseLightTheme)
- SQL History / Categories buttons no longer stay in hover after a dialog
  (retest: ignore fake Enter after the modal unless the cursor is on the button)
- Options Hide/Unhide sits at the right of Oracle, Aquarius, and USGS secret fields
- Oracle auth fail-fast is per database with a 5-minute pause (not all HDBs)
- SQL Query Builder dark panes use Base (editor, results, snippet list)
- Profile import merges Quick Looks with overwrite / skip / rename; SQL categories optional
- CSV export uses the focused SQL result tab
- Oracle Access List filters Internal Query and SQL Query Builder (Public still shows all)
- SQL snippets: right-click Delete in the pane and in Categories

## Notes

Windows launcher updates use the `DataDoctor-Python-*.zip` asset (`Update\` + `applyUpdate.cmd`).

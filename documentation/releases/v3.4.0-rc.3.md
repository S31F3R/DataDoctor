# Data Doctor 3.4.0-rc.3

Channel: rc

## Changes

- Windows update prompt says "Download, then hit Restart to apply." A second restart is asked only when the launcher command or the embedded Python actually changed. An already-current launcher is left in place.
- A 3.0.0 install gets that command on the next start after the Python zip, then is asked for the Windows package.
- Regression keeps every selected series that has a real lag, upstream or downstream, including several gages on the same wave, and names each series it leaves out under the stats.
- Regression tab has a hand-drawn icon.
- Wiki Regression page explains how the lag and the fit are chosen.
- Append New Row on the date column adds a named equation row at the bottom of Data Query. It saves with the Quick Look, covers every timestamp above it on the next query, and follows the column it was typed in.

## Notes

Windows: already on python-embed → `DataDoctor-Python-*.zip` + `applyUpdate.cmd`. Coming from 3.0.x → `DataDoctor-Windows-*.zip`, close the app, then `applyUpdate.cmd` (replaces the launcher).

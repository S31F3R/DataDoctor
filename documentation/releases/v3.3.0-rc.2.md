# Data Doctor 3.3.0-rc.2

Channel: rc

## Changes

- AppImage in-app update keeps the launched filename, relaunches, and does not leave updates/ or .sh next to the AppImage
- Version is 3.3.0-rc.1 (not 3.2.3-rc.1)
- Background update check every 4 hours; Later skips prompts until the next launch
- Aquarius Cloud is documented (on-prem and hosted tenants)
- Options → Appearance includes Overlay primary/secondary flag colors for the query list
- About Feature request is an in-app GitHub form (same as Report issue)
- USBR SDID-MRID uploads use MODIFY_M_TABLE
- Options Save no longer strips Log Viewer level colors
- AppImage Quit and apply waits for the file to unlock, logs to applyUpdate.log, and removes leftover updates/ + .sh next to the AppImage

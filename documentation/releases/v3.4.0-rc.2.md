# Data Doctor 3.4.0-rc.2

Channel: rc

## Changes

- Update available stays one window while it is open
- Test scripts use camel case names
- Linked HDB queries run at the same time, each on its own Oracle session
- About window stars drift behind the title
- Windows updates download the Windows package so the launcher and icon update
- Windows apply stages Python and applyUpdate.cmd, then swaps them after the updater exits
- Windows package leaves out python-standalone and a root applyUpdate.py, and apply removes leftovers
- Query, SQL, Plotter, and Graph tabs show icons
- Dictionary merge fills blank QAQC fields and keeps values you already set
- CSV bunker update accepts a folder or *.csv and reads the files in parallel

## Notes

Windows: already on python-embed → `DataDoctor-Python-*.zip` + `applyUpdate.cmd`. Coming from 3.0.x → `DataDoctor-Windows-*.zip`, close the app, then `applyUpdate.cmd` (replaces the launcher).

# Data Doctor 3.4.0-rc.1

Channel: rc

## Changes

- Download closes the update prompt before the progress bar; Later on Restart returns to the main window
- Graph legend hidden mark stays an open [ ] (does not collapse to [])
- Public overlay/delta pairs that include Aquarius run the remaining series as a normal column (do not re-pair with the next HDB)
- Right-click Regression: lagged fit, Relationship and Aligned views; double-click copies the Y line
- Regression keeps upstream and downstream when they share a wave; saved image includes the equation and stats
- Quick Look date dialog buttons sit under the list
- Equation formulas stay A1 across a new date range instead of #REF!
- Regression equation is Y = a*B + c with no [t] brackets or copy line; double-click copies that line
- Formula letters follow column insert, delete, and move
- Quick Look date dialog is owned by the Query window
- Lagged formulas stay on the row they were written; rows that would fall off the sheet stay blank
- Quick Look load keeps the formula start row (row 4 stays row 4)
- Fill handle hides when a query rebuilds the table
- Header details update max, min, and mean as cells change; custom columns show name, max, min, and mean and follow a rename
- Metadata details window minimizes to the app taskbar button
- Toolbar Plotter runs an API-only plot query (Line, Scatter, Time Lag) into one Plotter tab; table right-click Graph is unchanged
- Plot Quick Looks live in quickLook/plots/ and export with the profile
- Time Lag shifts the last series with a live slider; the hydrograph and correlation follow the visible time window
- Regression refusal is a dialog instead of a status-bar message
- Editing a query-list row changes Add Query to Update Query until the box is cleared or the row is saved
- Plotter closes after Plot; the progress bar stays on the main window
- Time Lag shows r², NSE, ME, RMSE, and N for the visible window above the slider
- HDB upload retries a change-agent lookup collision (ORA-00001 on IDX_REF_CHANGE_AGENT_LOOKUP)
- Long queries update the progress label while the timestamp rail and table are built
- Regression Relationship keeps the fit stats; Aligned scores each shifted series and adds NSE
- Time Lag gives every series after the first its own slider, colored like that line
- Each Time Lag slider has its own r², NSE, ME, RMSE, and N line in that line's color

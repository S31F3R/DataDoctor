# Data Doctor 3.3.0-rc.1

Channel: rc

## Changes

- About version number is a link to that build’s GitHub release notes
- Formula parser accepts Excel-style leading decimals (`.01` = `0.01`)
- Graph legend uses `[x]` / `[ ]` so Noto Sans no longer warns about glyph 9745
- Query Options are per-series flags (checkboxes bulk-flag; right-click to toggle). Overlay/delta pair consecutive flagged neighbors; unpaired flagged rows stay flagged but unhighlighted. Query list primary/secondary colors follow the theme
- Custom-column formulas are stored on the Query list and Quick Looks, filled for the whole time range, and break (`#REF!`) if a referenced series is removed
- Clear / Load Quick Look prompts to save when the list was changed from the Data Query table
- Data Dictionary Save shows the confirmation before the heavy UI refresh (crash after a successful write)
- AppImage live dictionary is `~/.config/Data Doctor/bunker.db`; Quit and apply relaunches and merges like Windows applyUpdate
- Answering N to Common Names / Data Types still inserts new packaged dictionary rows; identical bunker files skip prompts with a clear log line
- About / GitHub links open the system browser without leaking Qt plugin paths (fixes kde-open crash on click)
- Enter on a custom-column formula no longer fills the whole column; Quick Look query still does
- Equation query-list rows store the column header instead of `custom`
- Removing a column a formula referenced shows `#REF!` in the table immediately (no re-query)
- Query list / Quick Look equation rows show `EQUATION|<header>` (formula stored, not displayed); `#REF!` turns that row red
- AppImage in-app update keeps the launched filename, relaunches, and does not leave updates/ or .sh next to the AppImage
- Background update check every 4 hours; Later skips prompts until the next launch
- Aquarius Cloud is documented (on-prem and hosted tenants)
- Options → Appearance includes Overlay primary/secondary flag colors for the query list
- About Feature request is an in-app GitHub form (same as Report issue)
- USBR SDID-MRID uploads use MODIFY_M_TABLE
- Options Save no longer strips Log Viewer level colors

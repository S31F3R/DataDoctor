# Data Doctor 3.0.0-rc.2.4

Channel: rc

## Changes

- Query list right-click Delete (clicked row, or all selected)
- Internal HDB: KBOHDB / CUHDB / LBOHDB / ECOHDB use their own worker and a
  direct connection (no @link). UCHDB2 / LCHDB / YAOHDB still share links.
- Linked HDB @link failures retry a direct connect on any worker error
- Save Quick Look prefills the combo name and asks before overwrite
- Internal direct HDB SQL uses unqualified r_base / r_hour (not SCHEMA.r_base@dsn)
- Isolated HDB workers are internal-only; public USBR API stays one group
- MCS pool no longer pings idle sessions (Windows 0x80100070 cert-cache fatal)
- app.log rotation: faulthandler no longer locks the file; Windows copy+truncate
  fallback; Log Viewer reloads app.log + app.log.1…5
- sqlnet.log: ingest only bytes appended this process (no old Fatal dump);
  ERROR lines sit in the live app.log timeline
- SQL Query Builder: detachable tab, worksheets + pinned results, Stop/History,
  snippet categories, hide snippet pane (session worksheets, persisted history)
- SQL pin uses Pin vs Pinned hover/press sets; snippet splitter is a thin dotted
  grip; Categories dialog lists snippets and drag-moves them between groups
- Result-tab Pin/Pinned is painted on the tab bar (hover, press, Pin↔Pinned);
  setTabButton widgets never received those events. Pin tooltip uses Qt's
  delayed ToolTip event (no grabMouse)

## Notes

Windows launcher updates use the `DataDoctor-Python-*.zip` asset (`Update\` + `applyUpdate.cmd`).
